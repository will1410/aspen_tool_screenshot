Javascript notes

One of the things that this code adds to the image URL for the screenshots is that it wraps the <img> tag in an <a href=""> tag to open the screenshot in a new window. It also adds a class called "nsc-open-image-modal" to that anchor.

If you use this tool to create a collapsible image to insert in a basic or custom page in your Aspen and you have this custom javascript in your JavaScript Snippets, when you click on one of these images, it will open in a pop-up modal window at full size in the same window in your browser. This means you can see the full size image just by clicking on the image and your browser won't take you to a new window.

The custom code is:

<script>
  /* Adds the function that opens any <a> with the class "nsc-open-image-modal" in a modal window */
    $(document).on('click', 'a.nsc-open-image-modal', function (e) {
      
      /* Prevents the click from re-loading the page */
        e.preventDefault();

      /* Gets the URL for the image */
        var imageUrl = $(this).attr('href');

      /* Gets the image and the alt text */
        var imageAlt = $(this).find('img').attr('alt') || '';

      /* Puts the image and the alt text together into a new url for the modal window */
        $('#modalImage').attr({
          src: imageUrl,
          alt: imageAlt
        });

      /* Shows the modal window */
        $('#imageModal').modal('show');
    });
</script>

<script>
  $(document).ready(function () {

   /* Adds the modal only to Aspen Basic Pages and Portal Pages */
      if ($('body').hasClass('action_BasicPage') || $('body').hasClass('action_PortalPage')) {

        /* Builds the modal and attaches it to the basic and custom pages */ 
        /* so that the image has a modal to go into when the function is initialized */
          $('body').append(`
            <div class="modal fade" id="imageModal" role="dialog" tabindex="-1">
              <div class="modal-dialog" role="document" style="width: 100%; height: 100%; margin: 0;">
                <div class="modal-content" style="width: 100%; height: 100%; border: 0; border-radius: 0; background: #222;">
                  <button type="button"
                    class="close"
                    data-dismiss="modal"
                    aria-label="Close"
                    style="position: fixed; top: 10px; right: 20px; z-index: 9999; color: white; font-size: 40px; opacity: 1;">
                    <span aria-hidden="true">&times;</span>
                  </button>
                  <img class="img-responsive"
                    id="modalImage"
                    alt=""
                    style="position: absolute; top: 0; left: 0; width: 100vw; height: 100vh; object-fit: contain; padding: 10px;">
                </div>
              </div>
            </div>
          `);

        /* Puts the image created in the first step into the modal we just created */
          $(document).on('click', 'a.view-fullscreen-image', function (e) {
            e.preventDefault();

            $('#modalImage').attr({
              src: $(this).attr('href'),
              alt: $(this).find('img').attr('alt') || ''
            });

            /* Displays the modal pop-up */
              $('#imageModal').modal('show');
          });

      }

  });

</script>

About this project

The genesis for this project is simple. I wanted to add collapsible screenshots to basic pages in Aspen Discovery. Since Aspen uses Bootstrap, all of the tools for creating accordions and buttons, and other Bootstrap styled content is built in to Aspen, so adding that content is just a matter of writing the HTML for basic pages to include that content. This makes collapsible screenshots possible with Bootstrap.

The problem is that creating all of that HTML is kind of a pain. I first used templates so that all I had to do was to copy and paste a template into the web builder, but then you have to go in and add the content and change the IDs and some of the classes and that was also more work than I was willing to commit to. I wanted a way to form-fill the basic data and I came up with this form that only asks for three things - Title, URL, and Alt text. Then I added some checkboxes and radio buttons for different styles I wanted to mess around with. The result is the page you see here.

Another advantage of creating collapsible screenshots using this tool is that, if you work in environment where multiple people are creating pages in Aspen, having multiple people using a tool like this creates consistency in the look and feel of your pages. If every page builder in your organization is creating their own pages in their own style, your site will lose consistency.

The biggest caveat about the screenshots you create with this tool is that they are formatted for Bootstrap 5. If Aspen moves to a different version of Bootstrap that isn't backwards compatible with Bootstrap 5, then some of the Bootstrap elements that allow the screenshots to collapse may break and the code you add to Aspen may need to be updated.

This entire project is available on Github, so if you'd like to see the source code or if you'd like to download a copy of the project and change it to suit your needs, feel free to do so.
